# Change Log

All notable changes to the "wintry" theme are documented in this file. The VS Code
extension and the Neovim colorscheme share a single version, set in `package.json`.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.3]

### VS Code

- Increased active file background contrast
- Fixed status bar color when debugging

### Neovim

- Added a Neovim colorscheme built from the same palette, covering treesitter, LSP
  semantic tokens, diagnostics and common plugins
- Added a matching lualine theme
- The Lua palette is generated from `themes/Wintry-color-theme.json`

## [0.0.2]

- Fixed statusbar hover style

## [0.0.1]

- Initial release
